# Portfolio

Static site: no build step, no dependencies.

- Personal details, contact links, form endpoint, stack: `src/data/site.js`
- Projects: `src/data/projects.js` (add an entry, redeploy)
- Real screenshots: save to `assets/projects/` and set `image` on the project
- Deploy: drag this folder onto Netlify, or push to GitHub Pages / Vercel
- Preview locally: open `index.html`, or run `npx serve .`
